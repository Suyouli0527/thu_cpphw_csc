# 银行管理系统 — 命令大全

## 模式说明
| 模式 | 说明 | 提示符 |
|------|------|--------|
| 管理员模式 | 可用所有命令，含用户管理 | `admin[管理员] >` |
| 普通用户模式 | 可用账户命令 + 密码修改 | `username[普通用户] >` |
| 插卡模式 | 仅当前账户的操作命令，省略 id | `CARD[id] >` |

> 密码说明：`pwd` = 6位数字账户密码（100000~999999）；用户密码为字符串

---

## 账户操作

| 命令 | 格式 | 说明 |
|------|------|------|
| OPEN | `OPEN id type name balance pwd shared [repDay]` | 开立账户 |
| CLOSE | `CLOSE id pwd` | 关闭账户（余额须为0） |
| QUERY | `QUERY id pwd` | 查询账户详情 |
| QUERYALL | `QUERYALL` | 查询当前用户所有账户 |

### OPEN 参数详解
| 参数 | 说明 |
|------|------|
| id | 账户ID，正整数，不可重复 |
| type | 账户类型：`S` = 储蓄账户，`C` = 信用账户 |
| name | 账户名称 |
| balance | 初始余额（信用账户为额度） |
| pwd | 6位数字账户密码 |
| shared | 是否共享账户：`1` = 共享，`0` = 独占 |
| repDay | 还款日（仅信用账户需要，1~28） |

**示例：**
```
OPEN 1 S savings 1000.00 123456 0          开立储蓄账户
OPEN 2 C credit 5000.00 654321 1 15       开立共享信用账户，还款日15号
```

## 存取与转账

| 命令 | 格式 | 说明 |
|------|------|------|
| DEPOSIT | `DEPOSIT id amount pwd` | 存款 |
| WITHDRAW | `WITHDRAW id amount pwd` | 取款（储蓄账户） |
| TRANSFER | `TRANSFER srcId dstId amount pwd` | 转账（转出方密码） |

---

## 定期存款（仅储蓄账户）

| 命令 | 格式 | 说明 |
|------|------|------|
| FIXED_DEPOSIT | `FIXED_DEPOSIT id amount months pwd` | 定期存款 |
| FIXED_WITHDRAW | `FIXED_DEPOSIT id amount pwd` | 定期部分提前支取 |

### 定期利率
| 期限（月） | 3 | 6 | 12 | 24 | 36 | 60 |
|-----------|---|---|----|----|----|----|
| 年利率 | 1.35% | 1.55% | 1.75% | 2.25% | 2.75% | 3.00% |

> 到期后自动结算本息；提前支取部分按活期利率计息

---

## 信用账户操作（仅信用账户）

| 命令 | 格式 | 说明 |
|------|------|------|
| CONSUME | `CONSUME id amount pwd` | 消费（有宽限期） |
| CASH_ADVANCE | `CASH_ADVANCE id amount pwd` | 取现（次日起计息） |

### 信用计息规则
- **消费**：宽限至下月还款日，宽限期内免息，逾期按日计息
- **取现**：T+1 起按日计息，无宽限期

## 共享账户管理（仅管理员）

| 命令 | 格式 | 说明 |
|------|------|------|
| ADD_OWNER | `ADD_OWNER id username` | 添加共有人（2~5人） |
| REMOVE_OWNER | `REMOVE_OWNER id username` | 移除共有人（至少保留1人） |
