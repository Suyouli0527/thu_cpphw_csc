## 阶段一：系统启动与用户管理（5 条命令）

**展示要点**：两级用户体系（admin/normal）、用户 CRUD、用户查询

```
SWITCH admin admin
```
> 输出：`1`
> 讲解：系统默认用户 admin（密码 admin）和 default（密码 default），初始以 default 登录。SWITCH 切换到管理员。

```
CREATE_USER zhangsan abc123
```
> 输出：`1`
> 讲解：管理员创建普通用户 zhangsan。

```
CREATE_USER lisi xyz789
```
> 输出：`1`

```
WHOAMI
```
> 输出：`admin`（不输出 1，仅输出用户名）
> 讲解：查询当前登录用户。

```
QUERY_USERLIST
```
> 输出：
> ```
> USER admin 0
> USER default 0
> USER lisi 0
> USER zhangsan 0
> ```
> 讲解：管理员查看所有用户（按用户名排序），0 表示各用户关联 0 个账户。

## 阶段二：日期设置与开户（7 条命令）

**展示要点**：日期管理、两种账户类型（储蓄 S / 信用 C）、共享账户开户

```
SET_DATE 2024 1 1
```
> 输出：`1`
> 讲解：设置系统日期为 2024-01-01。仅接受向前推进（拒绝倒退），保证利息不重复。

```
SHOW_DATE
```
> 输出：`Monday, January 1, 2024`

```
OPEN 1001 S mysavings 50000 123456 0
```
> 输出：`1`
> 讲解：开设储蓄账户。参数：ID=1001, 类型=S, 名称=mysavings, 初始余额=50000, 密码=123456, 非共享(0)。

```
OPEN 2001 C creditcard 10000 15 654321 0
```
> 输出：`1`
> 讲解：开设信用账户。额外参数：信用额度=10000, 还款日=每月15日。

```
OPEN 3001 S shared_acct 20000 111111 1
```
> 输出：`1`
> 讲解：开设共享储蓄账户（最后一个参数 1 表示共享）。

```
OPEN 4001 S toclose 0 123123 0
```
> 输出：`1`
> 讲解：开设一个余额为 0 的账户，稍后用于演示销户。

```
QUERYALL
```
> 输出：
> ```
> 1001 S mysavings 50000.00 NOT_SHARED 0
> 2001 C creditcard 0.00 NOT_SHARED 10000.00 15 0.00 0.00
> 3001 S shared_acct 20000.00 SHARED 0
> 4001 S toclose 0.00 NOT_SHARED 0
> ```
> 讲解：查询当前用户的所有账户。信用账户额外显示信用额度、还款日、取现债务、消费债务。共享账户显示 SHARED 标识。

## 阶段三：存取转账（4 条命令）

**展示要点**：基本交易操作、账户密码验证

```
DEPOSIT 1001 10000 123456
```
> 输出：`1`
> 讲解：向储蓄账户 1001 存入 10000。余额变为 60000。

```
WITHDRAW 1001 2000 123456
```
> 输出：`1`
> 讲解：取出 2000。余额变为 58000。

```
TRANSFER 1001 3001 1000 123456
```
> 输出：`1`
> 讲解：从 1001 转账 1000 到 3001。原子操作——源账户取款成功才执行目标账户存款。

```
QUERY 1001 123456
```
> 输出：
> ```
>   账户ID: 1001
>   类型: 储蓄账户
>   名称: mysavings
>   余额: 57000.00
>   状态: 正常
>   共享: 否
>   定期存款: 0笔
> ```
> 讲解：查询账户详情。余额 57000 = 50000 + 10000 - 2000 - 1000(转账)。

## 阶段四：定期存款（4 条命令）

**展示要点**：6 种期限、多笔并存、提前支取惩罚、自动转存

```
FIXED_DEPOSIT 1001 10000 12 123456
```
> 输出：`1`
> 讲解：12 个月定期存款 10000。利率查表 getFixedRate(12) = 1.75%。余额变为 47000。

```
FIXED_DEPOSIT 1001 5000 6 123456 AUTO
```
> 输出：`1`
> 讲解：6 个月定期存款 5000，末尾 AUTO 标记自动转存。余额变为 42000。到期后本利自动续存。

```
FIXED_WITHDRAW 1001 3000 123456
```
> 输出：`1`
> 讲解：对 12 个月定期部分提前支取 3000。利息按活期利率（惩罚性低利率）计算。因同日操作持有天数=0，利息为 0。余额变为 45000。该笔定期标记为已支取，本金剩余 7000。

```
QUERY 1001 123456
```
> 输出：
> ```
>   账户ID: 1001
>   类型: 储蓄账户
>   名称: mysavings
>   余额: 45000.00
>   状态: 正常
>   共享: 否
>   定期存款: 2笔
>     [0] 本金:7000.00 期限:12月 存入:2024-1-1 到期:2024-12-31 [已部分支取]
>     [1] 本金:5000.00 期限:6月 存入:2024-1-1 到期:2024-6-29
> ```
> 讲解：显示两笔定期存款。第一笔已标记"已部分支取"（不可再次支取），第二笔 6 个月到期日为 6-29。

## 阶段五：信用账户操作（4 条命令）

**展示要点**：消费/取现分离计息、透支债务追踪、还款冲抵优先级

```
CONSUME 2001 3000 654321
```
> 输出：`1`
> 讲解：透支消费 3000。余额 = 0 - 3000 = -3000。透支部分计入 consume_debt（免息至下月还款日）。

```
WITHDRAW 2001 1000 654321
```
> 输出：`1`
> 讲解：透支取现 1000。余额 = -3000 - 1000 = -4000。透支部分计入 cash_debt（无免息期，次日起按日利率 0.05% 计息）。

```
DEPOSIT 2001 2000 654321
```
> 输出：`1`
> 讲解：还款 2000。余额 = -4000 + 2000 = -2000。仍在透支，不触发债务冲抵。

```
QUERY 2001 654321
```
> 输出：
> ```
>   账户ID: 2001
>   类型: 信用账户
>   名称: creditcard
>   余额: -2000.00
>   状态: 正常
>   共享: 否
>   信用额度: 10000.00
>   还款日: 每月15日
>   取现债务: 1000.00
>   消费债务: 3000.00 (免息期: 3000.00 逾期: 0.00)
> ```
> 讲解：三变量债务状态机——取现债务 1000（日计息）、免息期消费债务 3000（未计息）、逾期消费债务 0。下月 15 日免息期到期后，consume_debt 自动迁移到 consume_debt_overdue 开始计息。

## 阶段六：利息结算——日期推进（4 条命令）

**展示要点**：逐日计息 + 月复利、信用免息期迁移、定期到期自动结算

```
ADD_DAY 31
```
> 输出：`1`
> 讲解：推进 31 天到 2024-02-01。触发：(1) 储蓄账户 31 天活期利息 + 2 月 1 日月度复利结息；(2) 信用账户 31 天透支计息 + 1 月 15 日消费债务迁移到逾期。

```
QUERY 1001 123456
```
> 输出：（余额约 45043.xx，包含一个月活期利息）
> 讲解：活期利息已结入余额（月内单利、跨月复利）。

```
QUERY 2001 654321
```
> 输出：（余额约 -2042.xx，取现债务和逾期消费债务产生了利息）
> 讲解：1 月 15 日还款日，consume_debt 3000 迁移到 consume_debt_overdue（开始计息）。取现和逾期消费共产生约 42 元利息。

```
SHOW_DATE
```
> 输出：`Thursday, February 1, 2024`

## 阶段七：定期到期自动转存（2 条命令）

**展示要点**：6 个月定期到期自动续存、12 个月定期未到期保持不变

```
ADD_DAY 150
```
> 输出：`1`
> 讲解：推进 150 天到约 2024-07-01。6 个月定期（到期日 6-29）已到期，因 autoRenew=true，本利自动续存。12 个月定期未到期。

```
QUERY 1001 123456
```
> 输出：
> ```
>   定期存款: 2笔
>     [0] 本金:7000.00 期限:12月 存入:2024-1-1 到期:2024-12-31 [已部分支取]
>     [1] 本金:5038.75 期限:6月 存入:2024-7-1 到期:... [自动转存]
> ```
> 讲解：第 [1] 笔 6 个月定期已自动转存！本金从 5000 变为 5038.75（= 5000 + 5000×1.55%×6/12 = 5000 + 38.75），存入日更新为 2024-7-1，按相同期限续存。

## 阶段十四：日志查看与回滚（3 条命令）

**展示要点**：事件溯源式日志、回滚到任意历史状态

```
LOG
```
> 输出：（显示所有已记录的操作日志）
> ```
> 1 SWITCH admin admin
> 2 CREATE_USER zhangsan abc123
> 3 CREATE_USER lisi xyz789
> 4 SET_DATE 2024 1 1
> 5 OPEN 1001 S mysavings 50000 123456 0
> 6 OPEN 2001 C creditcard 10000 15 654321 0
> 7 OPEN 3001 S shared_acct 20000 111111 1
> 8 OPEN 4001 S toclose 0 123123 0
> 9 DEPOSIT 1001 10000 123456
> 10 WITHDRAW 1001 2000 123456
> 11 TRANSFER 1001 3001 1000 123456
> ... (后续所有成功执行的命令)
> ```
> 讲解：日志只记录成功执行的状态变更命令，查询/显示类命令不记录。这是事件溯源（Event Sourcing）的核心数据。

```
ROLLBACK 11
```
> 输出：`1`
> 讲解：回滚到第 11 条命令之后的状态。系统完全销毁当前状态（删除所有账户、重置用户、日期归零），然后从空白静默重放前 11 条命令。

```
SHOW_DATE
```
> 输出：`Monday, January 1, 2024`
> 讲解：日期已恢复到 SET_DATE 2024 1 1 时的状态。

```
QUERYALL
```
> 输出：
> ```
> 1001 S mysavings 50000.00 NOT_SHARED 0
> 2001 C creditcard 0.00 NOT_SHARED 10000.00 15 0.00 0.00
> 3001 S shared_acct 21000.00 SHARED 0
> ```
> 讲解：状态已恢复！注意：账户 4001（toclose）还未被创建（在第 8 条命令），转账还未发生。1001 余额=50000，3001 余额=20000+1000(转账)=21000。

> ⚠️ 回滚后 admin 密码恢复为 `admin`（因为 MODIFY_USERPASSWORD 在第 11 条之后）。

## 阶段十五：持久化保存与恢复（2 条命令 + 独立演示）

**展示要点**：跨会话状态恢复——SAVE 写文件、RESUME 从文件重建

```
SAVE defense_demo.log
```
> 输出：`1`
> 讲解：将当前日志保存到文件。

### RESUME 独立演示（需重启程序）

```bash
# 重启程序后
./bank.exe
```

```
RESUME defense_demo.log
```
> 输出：`1`
> 讲解：从文件读取命令并静默重放，恢复到保存时的状态。程序启动后初始日志为空（`isInitialState()` 检查），是 RESUME 的前置条件。

```
QUERYALL
```
> 输出：（应与 SAVE 前的状态一致）
> 讲解：验证恢复成功，状态与保存时完全一致。
